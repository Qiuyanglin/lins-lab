# 博士后招聘

## 研究方向
- 生物医学集成电路（Biomedical ICs）
- 神经接口电路（Neural Interfaces）
- 模拟 / 混合信号电路设计
- 超低功耗模拟前端
- 可穿戴与柔性电子系统

## 申请条件
- 已获得或即将获得 **电子工程、微电子、集成电路、计算机工程或相关专业博士学位**
- 具有 **模拟或混合信号集成电路设计经验**
- 在相关领域发表过高水平论文者优先
- 具备良好的科研能力、团队合作精神和英文写作能力

## 待遇
- 提供具有竞争力的薪酬
- 国际一流的科研环境与合作机会
- 支持参与 **ISSCC、VLSI、JSSC 等国际顶级会议与期刊研究**

## 研究方向
- Neural Interface Circuits

- Ultra-Low-Power IC Design

## 招生要求
