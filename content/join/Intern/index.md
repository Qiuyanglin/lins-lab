## 实习内容

我们欢迎具有科研兴趣的本科生加入实验室参与科研实践。  
本科实习生将在研究生或导师指导下参与基础电路模块设计与实验研究，并逐步了解集成电路设计与科研工作的基本流程。

实习内容可能包括：

- 放大器电路设计与分析（如运算放大器、低噪声放大器等）
- 模拟滤波器与信号调理电路设计
- 模数转换器（ADC）和数模转换器（DAC）的基础结构与设计方法
- 生物信号采集电路基础模块设计
- 电路建模、仿真与系统级验证
- 模拟/混合信号电路设计流程与EDA工具使用
- PCB板级电路设计与调试
- 模拟电路版图（layout）设计基础

## 实习收获

通过科研实习，你将有机会：

- 锻炼 **基础电路设计与工程实现能力**
- 学习 **电路建模、仿真与调试方法**
- 了解 **集成电路设计流程与版图设计基础**
- 接触 **PCB板级电路设计与实验验证**
- 学习 **科研工作的基本方法与研究思路**
- 参与实验室技术讨论与科研项目

表现优秀的本科实习生将有机会继续在本实验室开展科研或攻读研究生。

## 基本要求

- 电子工程、微电子、集成电路、生物医学工程或相关专业本科生
- 具备模拟或数字电路基础
- 对集成电路设计与科研探索有兴趣
- 具备良好的学习能力和团队合作精神

有以下经验者优先：

- MATLAB / Python
- Verilog / SystemVerilog
- Cadence 或 LTspice 电路仿真
- PCB设计工具（如 Altium / KiCad）
